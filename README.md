# AI Resume Analyzer

## 📌 Project Overview
AI Resume Analyzer is a Flask-based web application that extracts and analyzes resume data to evaluate skills, experience, and job suitability. It provides intelligent feedback to help users improve their resumes.

---

## 🚀 Features
- Upload resume in PDF format
- Extract text from resume
- Analyze skills and experience
- Provide job-fit suggestions
- Simple and user-friendly UI

---

## 🛠️ Tech Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- PDF parsing libraries

---
